# Machine Learning Algorithm Robustness Study

This project explores the robustness of a supervised classification algorithm under challenging data conditions such as class imbalance, noise, or multiclass settings.

The objective was to understand the algorithm both theoretically and empirically, and to propose a modification to improve its performance under specific data characteristics.

## Project Overview

The project was developed in two main phases:

### Phase 1 – Baseline Evaluation
- Implementation of a classification algorithm from scratch (without scikit-learn)
- Analysis of its theoretical behavior
- Empirical benchmarking on selected datasets
- Evaluation of performance under challenging data conditions

### Phase 2 – Algorithm Modification
- Proposal of a modification to improve robustness
- Implementation of the modified variant
- Comparative empirical evaluation against the original version

## Key Concepts

- Algorithm benchmarking
- Handling class imbalance / noise / multiclass data
- Experimental evaluation and performance comparison
